# Entrega AURORA 4.24 — MODO MOSTRADOR
Primera versión programada de conversación a dos caras:
- Lectura superior girada 180 grados.
- Entrada inferior de texto y botón para decirlo en voz alta.
- Reconocimiento con botón ESCUCHAR, con permiso de micrófono,
  transcripción visible, detener al finalizar y corte por tiempo.
- No hay servidor ni registro automático de las conversaciones.
- El servicio Android de reconocimiento podría requerir red.

Estado: verificado por pruebas CI si la compilación es exitosa.
Pendiente crítico: probar en Galaxy S9+ pantalla dividida, permisos,
texto, voz, teclado y cierre, y validar AURORA VOZ, alertas reales.
El MASTER PDF incluye instrucciones para recuperar toda la rama
de GitHub sin usar mensajes de chats anteriores.
