# AURORA 4.26: Entrega SOS

Esta entrega agrega SOS a contacto de confianza en COMUNICAR. El contacto se guarda únicamente al pulsar GUARDAR, el mensaje se edita, se revisa en diálogo y solamente se prepara un SMS o se comparte con otra aplicación. El envío siempre depende del usuario. La ubicación aproximada es opcional y se incluye solo cuando hay permiso y una posición reciente de menos de cinco minutos. No se reemplaza un servicio oficial de emergencias ni se comprueba recepción.

El MASTER incluye instrucciones para comenzar en otro chat, repositorio, rama y commit exacto. Prueba física en Samsung Galaxy S9+ pendiente. Próximas tareas: música háptica y validar alertas/voz/mostrador/SOS.
